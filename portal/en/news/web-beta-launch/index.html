Web app beta is live

The first public web beta is available on GitHub Pages. It is focused on browser access, local storage and the same protected source workflow used for the main app.

Included today

  • Raid, Blitz and Epic setup flows.
  • War and UA Planner.
  • Guild Planner without Gallery.
  • Friends and News tools.
  • Local browser storage.

Premium-only mobile features are not available in the web app.
