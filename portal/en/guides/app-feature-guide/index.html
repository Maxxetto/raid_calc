Complete Raid Calculator app guide

Raid Calculator is a local planning suite for Raid, Blitz, Epic, War, UA, Guild management, Friend Codes and event tracking. It is built to help you plan before spending energy, gems or time in-game.

Most data stays on your device or in your browser. There is no account sync, so exports and backups matter.

Android app and web app

The Android app is the full version. It includes the complete mobile toolset, Premium support, OCR screenshot import, Android OCR overlay and Guild Gallery.

The web app is a free browser version. It includes the main free planning tools, but it does not include Premium mobile features, Android OCR overlay or Guild Gallery images.

Use Android when you want the complete app. Use web when you want fast access from a browser, desktop planning, or a shareable lightweight version.

Feature availability

Available on both Android and web:

  • Raid, Blitz and Epic setup simulation;
  • Results and Graph View;
  • setup save, load, rename and JSON sharing;
  • Boss Stats, Elements, Elixirs, Pet tools and Pet Compendium;
  • Wargear Wardrobe and armor import;
  • Bulk Simulate for compatible saved setup comparisons;
  • War Calculator in free mode;
  • UA Planner;
  • Guild Planner roster, waiting list, strikes, buddying and JSON import/export;
  • Friends lookup and Hall of Fame data;
  • News events, Event Shop Planner and Guides;
  • themes, language selection and AMOLED mode.

Android-only:

  • Debug battle log;
  • Epic friends Premium section;
  • Wardrobe Simulate;
  • Raid Guild Planner inside War;
  • OCR screenshot import;
  • Android OCR overlay;
  • Guild Gallery, local screenshot albums and ZIP image export;
  • Android storage destinations such as Downloads/share flows.

Web differences:

  • the web app is free, local-only and has no real Premium entitlement;
  • Premium mobile features stay unavailable;
  • OCR screenshot import and overlay are not present;
  • Guild Gallery is hidden and Guild import/export is JSON-only;
  • data is stored in browser storage instead of Android app documents;
  • guide pages open in browser tabs from the GitHub Pages portal.

Raid, Blitz and Epic

The Raid tab is the main simulator. It lets you build a battle setup with boss mode, boss level, knights, armor, pet, pet skills, elixirs and simulation count.

Use it when you want to:

  • estimate your expected score before playing;
  • compare different knight, armor or pet builds;
  • test Raid, Blitz and Epic boss contexts;
  • understand whether a setup is stable or very swingy.

Recommended workflow:

1. Choose Raid, Blitz or Epic and set the boss context. 2. Enter knight stats, elements, stun and armor. 3. Configure pet stats, skills and pet bar behavior. 4. Add elixirs only if they match the plan you will actually use. 5. Run the simulation, then read both the average and the range.

Tip: do not judge a setup only by its best run. A setup with a slightly lower average but a tighter score range can be more reliable for real event planning.

Results and Graph View

Simulation results show summary values, score ranges, breakdowns and detailed tables. Graph View adds charts that make it easier to see the shape of the result instead of reading only numbers.

Graph View is useful for:

  • spotting score consistency;
  • checking threshold chances;
  • comparing multiple setups visually;
  • understanding which knight or source contributes most pressure.

If you are sharing results with a guild mate, use the result export tools so the other person can review the same report locally.

Saved setups and Bulk Simulate

Saved setups are for builds you want to reuse. You can save, load, rename, export and import setups as JSON.

Use saved setups for:

  • keeping different boss builds ready;
  • comparing pet or armor variants;
  • sharing a setup with another player;
  • preparing Bulk Simulate.

Bulk Simulate compares multiple saved setups in one pass. It is best when you already have several serious candidates and want a cleaner comparison than running them one by one.

Debug battle log

Debug runs a deterministic battle and shows a turn-by-turn log. It is designed for investigation, not for normal planning.

Use it when:

  • a skill interaction looks strange;
  • a result seems lower or higher than expected;
  • you want to copy a detailed log for troubleshooting.

Debug is a Premium mobile feature and is not available as a Premium feature on web.

Pet tools and Pet Compendium

Pet tools let you configure pet stats, elements, skill slots, custom skill values and pet bar order.

The Pet Compendium helps you find pets faster. You can search by pet, family or skill, then import a pet directly into the setup.

Practical tips:

  • check that pet elements match the setup you are testing;
  • review custom skill values if you are testing unusual conditions;
  • save favorite pets when you reuse the same families often.

Wargear, favorites and Universal Armor Score

Wargear Wardrobe helps you browse and import maxed armor sets. You can filter by element, role, guild rank, guild element bonus and Base or Plus version.

Imported armor can show badges for role, rank and version. Tapping those badges cycles the armor context and recalculates stats quickly.

Universal Armor Score is a fast contextual armor score. It reacts to boss, pet, knight slot and final armor stats. Use it as a shortcut for deciding what is worth simulating next.

Important: Universal Armor Score is a guide, not a full simulation. When the choice matters, simulate the final setup.

Wardrobe Simulate tests generated armor combinations with the real simulator and reports the best candidates. It is Premium-only on Android.

OCR screenshot import and Android OCR overlay

On Android, OCR screenshot import can read knight stats from a screenshot. You can adjust crop values and review the detected numbers before applying them.

The Android OCR overlay is a mobile-only workflow that can work over the game and help transfer party information into the app. It requires Android overlay and screen capture permissions.

These tools are not available on web.

Tip: always review OCR results before saving or simulating. OCR is a time saver, not something to trust blindly.

War Calculator

The War tab helps plan milestones, normal attacks, Power Attacks, energy, gems, server point sets, Strip, Frenzy and elixirs.

Use it when you want to answer:

  • how many attacks do I need;
  • how much energy is missing;
  • how many gems would this target cost;
  • whether a Power Attack strategy is worth it;
  • how EU and Global values affect the plan.

The Raid Guild Planner inside War is a Premium mobile tool for guild score planning. It is not available as a Premium feature on web.

UA Planner

UA Planner helps track monthly progress, event rewards, placements, bonus conditions and calendar cadence.

Use it for:

  • Elite and Elite Plus forecasting;
  • monthly event planning;
  • tracking score and placement entries;
  • reviewing War, War Blitz, Raid, Raid Blitz, Heroic and Blitz Arena dates;
  • exporting or importing planner state.

Tip: update UA Planner regularly during the month. It is much more useful as a live planning sheet than as a last-day calculator.

Guild Planner

Guild Planner is for guild managers and players who help organize rosters. It supports up to 5 guilds.

Each guild can have:

  • up to 40 active roster members;
  • up to 30 waiting-list members;
  • rank caps for active roster members: 1 GM, 1 GS, 1 GC and 10 HC;
  • global minimum score and personal minimum overrides;
  • strikes with history;
  • buddying notes for score coverage;
  • modular import/export.

Recommended workflow:

1. Create a guild. 2. Add members directly from the guild screen. 3. Use Search when the profile already exists, or Create member when you need a new profile. 4. Set rank and personal minimums only where needed. 5. Use strikes as manual reminders. 6. Use buddying when one player is covering score for another.

On Android, Guild Gallery can store event screenshot albums and export images in ZIP backups. On web, Gallery is disabled and Guild backups are JSON-only.

Friends

The Friends tab is a searchable friend code archive. You can filter by server and platform, then copy codes quickly.

Use it when you need:

  • a fast friend code lookup;
  • active contact references;
  • Hall of Fame data from the local asset archive.

News and Event Shop

The News tab shows active, recently ended and upcoming events from local data. Event Shop Planner helps calculate shop currency needs from selected items and current inventory.

Use it to:

  • track event windows;
  • mark completed event rows;
  • plan shop purchases;
  • check how much currency remains after your owned resources.

Recent news appears below the event cards for release notes and app updates. The Guides block appears after Recent news, at the bottom of the News tab, so app guides stay easy to find. On Android and web, portal content tries GitHub Pages first, then a local cache, then the bundled fallback. If the phone is offline, the News tab keeps working with local event data.

Themes, language and AMOLED

The app supports themes, AMOLED mode and multiple languages. Theme and language choices are saved locally.

If something looks visually wrong after changing theme, it is worth reporting, especially on shared features such as Guild, UA, War and News.

Premium on Android

Premium is handled through the Android app store flow. It can unlock mobile-only features such as Debug, expanded setup capacity, Premium planning tools, Epic friends, extended favorites or elixir limits and extra metrics where available.

Premium is not active on web. The web app stays free, local and informational.

Backup and data safety

Because the app is local-first, backups are important.

Good habits:

  • export important setups before clearing app or browser data;
  • export Guild data before reorganizing large rosters;
  • use Guild ZIP export on Android when Gallery images matter;
  • use JSON export/import when moving between devices;
  • remember that browser data can disappear if you clear site storage.

Quick section guide

  • Raid: simulate Raid, Blitz and Epic setups.
  • War: plan attacks, energy, gems and milestones.
  • UA Planner: track monthly UA progress and event cadence.
  • Guild: manage guild rosters, strikes, buddying and backups.
  • Friends: search and copy friend codes.
  • News: follow events and plan event shop currencies.

Start with the section that matches the question you are trying to answer. The app works best when it is used as a planning companion before committing resources in-game.
